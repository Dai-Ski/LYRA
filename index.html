Installation Steps

1

Open Lyra.dmg

Double-click Lyra.dmg in your Downloads folder to mount the installer.

2

Drag to Applications

Drag Lyra into Applications.

3

First Launch (Gatekeeper Notice)

If macOS shows "Apple could not verify Lyra is free of malware", choose one:

  • Go to System Settings → Privacy & Security and click Open Anyway.
  • Right-click Lyra.app in Applications → select Open.
  • Or copy & run this command in Terminal:
xattr -cr /Applications/Lyra.app
