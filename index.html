3

First Launch Security Notice (Gatekeeper)

If macOS displays "Apple could not verify Lyra is free of malware", choose one:

  • Option A: Go to System Settings → Privacy & Security and click Open Anyway.
  • Option B: Right-click Lyra.app in Applications → Select Open.
  • Option C (Terminal): Run this 1-line command in Terminal:
xattr -cr /Applications/Lyra.app
