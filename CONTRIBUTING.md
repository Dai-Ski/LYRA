# Contributing to Lyra 🤝

Thanks for helping improve Lyra!

### 1. Issues & Feature Requests
* **Bug Reports & Ideas**: Open a ticket via [GitHub Issues](https://github.com/Dai-Ski/LYRA/issues).
* **Questions & Support**: Reach out on [Telegram](https://t.me/dai_ski) or check [SUPPORT.md](SUPPORT.md).

### 2. Submitting Pull Requests
1. Fork the repository and create your branch from `main`.
2. Ensure tests compile and pass:
   ```bash
   swift test
   ```
3. Submit a Pull Request describing your changes.
